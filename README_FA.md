# DICE DUEL — نسخه اولیه آزمایشی

این پروژه یک اسکلت اولیه برای بازی دو نفره تاس در Telegram Mini App است.
در این نسخه فقط **امتیاز مجازی و غیرقابل برداشت** استفاده می‌شود؛ هیچ پرداخت یا توکن واقعی وجود ندارد.

## پیش‌نیازها
- Python 3.11 یا جدیدتر
- یک ربات تلگرام ساخته‌شده با @BotFather
- آدرس HTTPS برای انتشار Mini App (برای آزمایش محلی می‌توان از ابزار تونل امن استفاده کرد)

## اجرای محلی
1. فایل `.env.example` را به `.env` تغییر نام دهید.
2. توکن ربات را فقط در فایل `.env` روی رایانه/سرور خود قرار دهید؛ آن را در چت یا کد عمومی ارسال نکنید.
3. در ترمینال، داخل پوشه پروژه اجرا کنید:

   `python -m venv .venv`

   ویندوز:
   `.venv\\Scripts\\activate`

   لینوکس/مک:
   `source .venv/bin/activate`

4. نصب وابستگی‌ها:
   `pip install -r requirements.txt`

5. اجرای سرور:
   `uvicorn app:app --reload`

6. صفحه آزمایشی در `http://127.0.0.1:8000` باز می‌شود.
   توجه: اجرای واقعی داخل تلگرام به HTTPS و تنظیم Mini App در BotFather نیاز دارد.

## نکات مهم
- تا وقتی `BOT_TOKEN` و `REQUIRE_TELEGRAM_AUTH=true` تنظیم نشده باشد، API بازی عمداً درخواست‌های بازی را نمی‌پذیرد.
- این اسکلت برای توسعه و آزمایش است، نه انتشار عمومی یا نگهداری دارایی واقعی.
- قبل از انتشار عمومی باید احراز هویت Telegram WebApp، محدودسازی درخواست‌ها، ثبت رویدادها، پشتیبان‌گیری، آزمون امنیتی و بررسی حقوقی انجام شود.
- نتیجه تاس فقط روی سرور تولید می‌شود. کلاینت حق تعیین عدد تاس یا موجودی را ندارد.
